# static-websides-using-html-css

HTML & CSS Responsive Web Design Projects
A collection of static website projects built using HTML5 and CSS3 to master frontend development, responsive layouts, Flexbox, CSS Grid, animations, transitions, forms, and modern UI design. Projects include a Coding School website, Personal Portfolio, Amazon-inspired E-commerce UI, Netflix-inspired Streaming UI, Registration and Login Pages, and Usability Hub-inspired landing pages. Focused on clean code, reusable layouts, mobile-first design, and real-world frontend development skills.
